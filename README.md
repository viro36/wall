
## О проекте

Веб-приложение для сбора и обработки вопросов и предложений от граждан, связанных с образовательными организациями. Платформа позволяет пользователям задавать вопросы, предлагать решения, голосовать за предложения и комментировать.

### Основные возможности

* **Создание вопросов** - пользователи могут задавать вопросы, привязываясь к конкретным образовательным организациям
* **Предложения** - возможность предлагать решения к вопросам с форматированием текста через CKEditor
* **Голосование** - система лайков/дизлайков с возможностью отмены голоса
* **Комментарии** - древовидная структура комментариев с возможностью отвечать
* **Лучшее предложение** - администраторы могут отмечать лучшее предложение, после чего вопрос закрывается
* **Фильтрация** - поиск и фильтрация по организациям, районам, типам организаций
* **Статистика** - счетчики просмотров, предложений, голосов
* **Загрузка изображений** - встроенный редактор CKEditor с возможностью загрузки изображений
* **HTMX** - динамическое обновление страниц без перезагрузки

## Технологический стек

### Backend

* **Python 3.14**
* **Django 6.0.3** - основной фреймворк
* **Django REST Framework** - API для фронтенда
* **Celery** - асинхронная обработка задач
* **PostgreSQL + PostGIS** - база данных с поддержкой геоданных
* **Redis** - кэширование и брокер сообщений

### Frontend

* **Bootstrap 5** - адаптивный дизайн
* **HTMX** - динамические обновления
* **Alpine.js** - интерактивность на клиенте
* **CKEditor 5** - WYSIWYG редактор
* **Font Awesome** - иконки

### Инфраструктура

* **Docker / Docker Compose** - контейнеризация
* **Nginx** - веб-сервер
* **Gunicorn** - WSGI сервер
* **Flower** - мониторинг Celery
